# Деплой 123.info на Vercel

Пошаговая инструкция от локального кода до рабочего продакшен-домена.

## Шаг 1: Подготовка Git-репозитория

Если проект ещё не под git — инициализируйте репозиторий и сделайте первый
коммит:

```bash
git init
git add .
git commit -m "Initial commit"
```

Создайте пустой репозиторий на GitHub (без README/gitignore — они уже есть
локально), затем привяжите его как remote и запушьте код:

```bash
git remote add origin https://github.com/<ваш-аккаунт>/123-info-summarizer.git
git branch -M main
git push -u origin main
```

> Убедитесь, что `.env.local` **не попал** в коммит — он в `.gitignore`
> (шаблон `.env*`), но перепроверьте `git status` перед первым коммитом.

## Шаг 2: Деплой на Vercel

1. Зайдите на [vercel.com](https://vercel.com) и войдите (можно через
   GitHub-аккаунт).
2. Нажмите **Add New → Project → Import Git Repository**.
3. Выберите GitHub, авторизуйте доступ, если потребуется, и найдите
   репозиторий `123-info-summarizer`.
4. Vercel автоматически определит фреймворк как **Next.js** (это также
   зафиксировано в `vercel.json`).
5. В разделе **Environment Variables** добавьте:
   - `ANTHROPIC_API_KEY` = ваш реальный ключ из консоли Anthropic
   - (опционально) `NEXT_PUBLIC_APP_URL` = будущий публичный URL
     (например, `https://123.info`)
6. Нажмите **Deploy** и дождитесь окончания сборки (обычно 1–2 минуты).

По завершении Vercel выдаст временный URL вида
`https://123-info-summarizer-xxxx.vercel.app` — проект уже доступен и
рабочий с этим адресом.

## Шаг 3: Привязка домена 123.info

1. В проекте на Vercel откройте **Settings → Domains**.
2. Введите `123.info` и нажмите **Add**.
3. Vercel покажет, какие DNS-записи нужно добавить у вашего
   регистратора домена:
   - Для корневого домена (`123.info`): **A**-запись → `76.76.21.21`
   - Для поддомена `www` (если нужен): **CNAME**-запись →
     `cname.vercel-dns.com`
4. Добавьте эти записи в панели управления DNS вашего регистратора и
   дождитесь распространения (обычно от нескольких минут до пары часов).
5. Vercel автоматически выпустит SSL-сертификат после того, как DNS
   подтвердится.

## Шаг 4: Проверка работы

1. Откройте задеплоенный URL (временный `*.vercel.app` или уже
   привязанный `123.info`).
2. Вставьте любой текст во вкладке «Текст» и нажмите «Получить суть
   1-2-3».
3. Откройте DevTools → вкладку **Network**, найдите запрос
   `POST /api/summarize` и убедитесь, что:
   - Статус ответа `200`.
   - Тип содержимого — потоковый текст (`Content-Type: text/plain`),
     и ответ приходит частями (стриминг), а не одним блоком.
4. Убедитесь, что текст в карточке результата появляется постепенно, а
   не мгновенно целиком — это подтверждает, что стриминг работает
   end-to-end в продакшене.
5. Проверьте кнопку «Копировать» и сценарий с невалидной ссылкой —
   должна появляться понятная ошибка на русском.
