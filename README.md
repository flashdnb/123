# 123.info — суть любого текста за 3 пункта

Бесплатный AI-сервис, который превращает длинные статьи, ссылки и документы
в три четких пункта: **главная мысль**, **ключевые факты и цифры** и
**что с этим делать**. Никакой «воды» — вставляешь ссылку или текст,
получаешь суть за несколько секунд.

Философия проекта простая: чем меньше времени нужно, чтобы понять, стоит ли
читать материал целиком, тем полезнее сервис. Ответ модели всегда приходит
в одном и том же строгом формате, на русском языке, без вступлений и
заключений.

## Стек технологий

- **Next.js 16** (App Router, Turbopack)
- **TypeScript** (strict mode)
- **Tailwind CSS v4**
- **Framer Motion** — анимации интерфейса
- **lucide-react** — иконки
- **Anthropic API** через **Vercel AI SDK** (`ai`, `@ai-sdk/anthropic`) —
  модели `claude-haiku-4-5` (быстро) и `claude-sonnet-4-6` (качественно)
- **cheerio** — извлечение текста статьи по ссылке
- **react-markdown** + **remark-gfm** — рендер ответа модели
- **Ручной стриминг** ответа: `fetch` + `ReadableStream` + `TextDecoder`
  на фронтенде, `streamText` + `createTextStreamResponse` на бэкенде
  (без `useChat`/`useCompletion` — в установленной версии `ai` этих
  хуков нет, поэтому стриминг реализован вручную)
- **zod** — валидация запросов и URL

## Как запустить локально

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <адрес-репозитория>
   cd 123-info-summarizer
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Настройте переменные окружения. Скопируйте `.env.local` (или создайте
   его) и укажите свой ключ:

   ```bash
   ANTHROPIC_API_KEY=sk-ant-...
   NEXT_PUBLIC_APP_URL=http://localhost:3000
   ```

4. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

5. Откройте [http://localhost:3000](http://localhost:3000).

## Где взять API-ключ

Ключ выдаётся в консоли Anthropic:
[console.anthropic.com](https://console.anthropic.com/settings/keys).
Зарегистрируйтесь, создайте новый API-ключ и вставьте его в
`ANTHROPIC_API_KEY` в `.env.local` (локально) или в переменные окружения
хостинга (в проде).

Без ключа (или с заглушкой `your_key_here`) API-роут `/api/summarize`
сразу вернёт понятную ошибку конфигурации вместо тихого сбоя.

## Деплой на Vercel

Кратко:

1. Запушьте код в свой репозиторий на GitHub.
2. Нажмите кнопку ниже (или зайдите на [vercel.com](https://vercel.com) →
   **Add New → Project → Import Git Repository**) и выберите репозиторий:

   [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

3. При настройке проекта добавьте переменные окружения:
   - `ANTHROPIC_API_KEY` — ваш реальный ключ из консоли Anthropic
   - `NEXT_PUBLIC_APP_URL` — публичный домен деплоя (например,
     `https://123.info`)

4. Нажмите **Deploy**. Vercel автоматически соберёт и опубликует проект
   (конфигурация сборки уже зафиксирована в `vercel.json`).

После первого деплоя не забудьте обновить `SITE_URL` в
`app/layout.tsx`, если домен отличается от `123.info`.

Полная пошаговая инструкция — включая подготовку Git-репозитория,
привязку домена `123.info` (DNS-записи) и проверку стриминга в
продакшене — в файле [`DEPLOYMENT.md`](./DEPLOYMENT.md).
